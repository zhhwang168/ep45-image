# EP45 · ChatGPT Images Example Gallery

**[Open the live gallery on Cloudflare Pages](https://ep45-image.pages.dev/)**

This gallery accompanies Tube U’s EP45 tutorial on creating and editing images with ChatGPT. Follow one orange-and-white robot through animated GIFs, targeted edits, background swaps, SVG examples, thumbnail design, and transparent stickers.

Browse the examples by category. Select a card to see the image and its prompt, then adapt the prompt to your own subject. Use the before-and-after examples to compare the results.

The gallery is available in English, 简体中文, and 日本語.
